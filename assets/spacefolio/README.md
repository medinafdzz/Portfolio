# SPACEFOLIO source assets

Original models generated for this portfolio. No meshes, textures or character
assets from the reference room are redistributed here. Planet maps retain their
existing attribution under `public/textures/ATTRIBUTION.md`.

Tool verified: Blender 5.3.0 Release Candidate, build `c956fd684542`.
Both CPU and AMD HIP (Radeon RX 9070 XT) baking/export passed a small pipeline
test. Blender is a build-time tool; the website only loads the resulting GLB.

Rebuild from the repository root:

```powershell
node assets/spacefolio/build.mjs "<absolute path to blender.exe>" --device HIP --samples 128 --preview
node --test tests/model-assets.test.mjs
```

`build.mjs` exports the live web coordinates/palette from `config.js`; there is
no second hand-maintained position table. Use `--device CPU` if HIP is unavailable.
The generation temporarily uses the GPU/CPU; it does not add work to idle web
pages. `--preview` writes an authoring render to ignored `artifacts/`.

Outputs: editable `scene.blend`, `cabin-light.png` (2048² diffuse illumination),
`manifest.json` (tool version, samples, geometry and source configuration), and
`public/models/spacefolio.glb`. The GLB parts use local coordinates and stable
names so React retains the animation pivots. The saved Blender source is laid
out in the actual cabin arrangement for editing. It deliberately omits web-only
Moon maps, screen text and HTML; inspect final web captures for those elements.

Only CabinShell, ConsoleBody and Chair are light-baked. Animated models are
excluded from the atlas bake and use shared vertex-color illumination. The three static nodes
share one atlas exported with KHR_materials_unlit to avoid double lighting.

Geometry is exported with Draco (level 6, position 14 bits, normal 12 bits, UV
16 bits). See `manifest.json` for the exact generated byte and triangle counts.
The unmodified decoder is served from `public/draco/` with its Apache license;
one worker bounds decode concurrency and is terminated after loading. This is loading-time compression, not
an ongoing rendering effect. No additional npm dependency is required.

Performance: `node tests/performance.mjs <label> http://127.0.0.1:5173/ <mode>`.
Modes are `software`, `default`, `hardware`. Reports record the actual renderer,
separate main/shadow passes, resource sizes and aggregate process CPU; 100% is
one logical core. Software results must never be labelled hardware GPU results.

The refined medal, red wall phone and sculpted mini-Earth are original meshes,
inspired by the three Sketchfab references linked in the implementation plan.
Those references were not downloadable; no viewer model was extracted.
`Satoshi-Bold.otf` is the user's original, unmodified font, converted to mesh
only for the medal numeral and phone keypad. Its license is retained in
`public/fonts/Satoshi-LICENSE.txt`. The build fails if the font is missing.
The phone cord was removed. LaptopBase/LaptopLid retain a real hinge pivot.
The planet has raised coastlines, mountain caps, forest cones and opaque clouds;
it shares the existing GLB and does not request the old Earth photography.

The pressure hull surrounds the whole cabin/camera, with one window aperture.
Non-atlas meshes store studio illumination in vertex colors and share one
unlit material; each rigid part exports one primitive. Normals and unused UVs
are omitted because the browser no longer calculates lighting. The embedded
atlas uses JPEG quality86. `cabin-light.png` remains the lossless editable source.
The robot's lower chair and reversible Bezier route keep its seated feet near
the floor and allow it to rise to a genuinely higher head position.

`spacefolio-lite.glb` is exported from simplified copies (22% collapse ratio),
with the same part names and pivots. Software WebGL loads only that asset;
hardware WebGL loads only `spacefolio.glb`. There is no unconditional full-model
preload. `manifest.json.cpu_detail` records its byte/triangle budget. The normal
editable scene keeps its full geometry. Resource tests enforce exclusive loading
and termination of all decoder workers after the cached scene is ready.
